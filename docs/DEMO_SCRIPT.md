## 🎯 Key Judge Talking Points & Answers

1. **Q: How does IntentOS operate without paid APIs?**
   - *A: We designed a modular provider architecture. IntentOS includes a deterministic local AI engine and local Web Speech synthesis with sub-second response times, plus an optional Ollama local LLM adapter for offline environments.*

2. **Q: Is the voice agent ethical and compliant?**
   - *A: Yes. Every autonomous call begins with explicit AI disclosure, respects call windows, supports instant human representative handoff, and records immutable audit logs for enterprise compliance.*

3. **Q: How does IntentOS avoid generic scoring?**
   - *A: Our 8-dimensional model evaluates extracted evidence (explicit scope count, procurement deadline, decision-maker title, firmographic tech stack) rather than generic keywords.*
